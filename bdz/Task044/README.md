# Task044 - Арифметика указателей 🔍

## Задание
- Что такое арифметика указателей в языке C?
- Почему прибавление числа к указателю сдвигает его не на байты, а на элементы соответствующего типа?
- Чем отличается выражение p + 1 от выражения ((char*)p) + 1?
- Попробуйте изменить значение смещения (например, p + 10) и посмотрите, что произойдёт. Объясните результат.


Что такое арифметика указателей?
Это операции сложения/вычитания с указателями — сдвиг на N элементов того типа, на который указывает указатель.
cint a[5] = {10, 20, 30, 40, 50};
int *p = a;  // p указывает на a[0]

*(p + 0)  // 10 — a[0]
*(p + 1)  // 20 — a[1]
*(p + 2)  // 30 — a[2]

Почему сдвиг на элементы, а не на байты?
Компилятор автоматически умножает смещение на sizeof(тип):
c// int занимает 4 байта
p + 1  →  адрес + 1 * sizeof(int)  →  адрес + 4 байта
p + 2  →  адрес + 2 * sizeof(int)  →  адрес + 8 байт
Это сделано специально, чтобы указатель всегда попадал ровно на следующий элемент.

Чем отличается p + 1 от ((char*)p) + 1?
cint x = 0x01020304;
int *p = &x;

p + 1           // сдвиг на sizeof(int) = 4 байта → следующий int
((char*)p) + 1  // сдвиг на sizeof(char) = 1 байт → второй байт внутри x
