казатель — это переменная, которая хранит адрес памяти другой переменной.
cint value = 42;
int *ptr = &value;  // ptr хранит адрес value
*ptr = 100;         // разыменование — обращение к значению по адресу

Как работает const для указателей?
Есть два разных случая:
cint const *const_ptr = &value;
// const стоит ДО * — нельзя менять ЗНАЧЕНИЕ по указателю
// *const_ptr = 50; ❌ — значение защищено
// const_ptr = &other; ✅ — сам указатель менять можно

int * const ptr_const = &value;
// const стоит ПОСЛЕ * — нельзя менять САМ УКАЗАТЕЛЬ
// ptr_const = &other; ❌ — указатель защищён
// *ptr_const = 55;    ✅ — значение менять можно

Что не компилируется и почему?
c*const_ptr = 50;      // ❌ значение защищено const
ptr_const = &other_var; // ❌ указатель защищён const
Они закомментированы — поэтому программа компилируется.

Undefined Behavior
cint *uninitialized;
printf("%d\n", *uninitialized); // ❌ UB!
Указатель не инициализирован — содержит мусорный адрес. Чтение по нему — Undefined Behavior: может вернуть случайное число, упасть, или работать "нормально".

SEGFAULT
cint *null_ptr = NULL;
printf("%d\n", *null_ptr); // 💥 SEGFAULT!
SEGFAULT будет — разыменование NULL всегда вызывает Segmentation Fault, потому что адрес 0 — зарезервированная память, к которой процессу доступ запрещён.
С uninitialized — SEGFAULT может быть, а может и не быть, зависит от того, куда случайно указывает мусорный адрес. Это и есть UB.
